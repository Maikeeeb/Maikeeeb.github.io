Decisions & tradeoffs.

Open each note for the implementation boundary, tradeoff, and next engineering question.

01Types and runtime checks serve different boundaries

Static types constrain code before execution, while external input still needs runtime validation. That distinction informs my approach to payloads, configuration, and internal application models.

02Concurrency needs an ownership model

Threads share resources even when their control flow appears independent. Locks and semaphores coordinate access, but ordering, blocking calls, and resource lifetimes still determine whether a design can race or deadlock.
