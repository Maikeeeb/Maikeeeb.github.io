For a closer technical review

Decisions & tradeoffs.

Open each note for the implementation boundary, tradeoff, and next engineering question.

01Composition makes timing explicit

The compiler uses clip durations and start offsets to build a CompositeVideoClip. Overlap and transition duration interact: short inputs expose timing edge cases. A revision should calculate one explicit timeline and validate every resulting interval.

02Collection is a separate failure boundary

Scraping and downloading depend on website structure and network availability. Local composition can be tested with known media, while collection needs retry limits, clear failure reports, and source-rights review.
