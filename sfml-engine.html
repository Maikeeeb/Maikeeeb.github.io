The starting point

Why build it?

Many behaviors cooperate every frame. Separating them into systems makes their responsibilities and update order easier to reason about.

For a closer technical review

Decisions & tradeoffs.

Open each note for the implementation boundary, tradeoff, and next engineering question.

01An ECS separates data from iteration

Systems operate on entities with the required components rather than placing every behavior in one hierarchy. Dependencies between systems become update-order contracts that need documentation and tests.

02Collision has frame-boundary limits

Axis-aligned boxes provide straightforward overlap checks. Fast movement, corners, and large frame times challenge discrete collision handling. Fixed-step simulation and swept tests are possible extensions, not features claimed here.
